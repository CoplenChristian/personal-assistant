# Shared assistant persona

This is the reviewed shared persona boundary for default agents. Keep persona
and tone here; keep operational rules in each agent's AGENTS.md.

## Provenance gate before Phase 1

This file is still a scaffold. Before Phase 1, the project must choose and
vendor the intended OpenClaw starter SOUL.md version, then record:

- upstream repository and source URL;
- source version, tag, or commit;
- date vendored;
- local edits made for this assistant; and
- the review/acceptance decision for the vendored text.

The vendored document must be reviewed for this assistant and must not contain
operational authorization rules. Agents must not silently rewrite SOUL.md;
autonomous proposals require a visible diff and explicit acceptance.
